# 试驾页使用、配置与发布手册

## 1. 页面与组件

| 用途 | 路径 |
| --- | --- |
| AEM Author 页面 | `/content/demo-site/language-master/en/test-drive` |
| EDS Preview | `/language-master/en/test-drive` |
| EDS Live | `/language-master/en/test-drive` |
| 业务 Block | `lixiang-test-drive-booking` |
| 车型 item | `test-drive-model` |
| 门店 item | `test-drive-store` |

页面只使用一个 `Lixiang Test Drive Booking` Block。车型选择、门店选择、字段校验和提交成功都是组件内部状态，不应拆成额外 Block。

## 2. Block 文案配置

选择 `Lixiang Test Drive Booking` 后，在 Properties 中维护：

| 字段 | 必填 | 用途 |
| --- | --- | --- |
| `ID` | 否 | 页内锚点 |
| `Title` | 是 | 表单标题，例如 `Schedule a Drive` |
| `Contact Notice` | 是 | 表单底部的联系说明 |
| `Privacy Consent Text` | 是 | 隐私同意句 |
| `Privacy Notice Link` | 是 | 隐私声明页面 |
| `Privacy Link Text` | 是 | 隐私链接文案 |
| `Submit Label` | 是 | 提交按钮文案 |
| `Success Title` | 是 | 成功状态标题 |
| `Success Description` | 是 | 成功状态说明 |

姓名、邮箱、电话等输入值属于访问者数据，不写入 AEM 内容、URL、日志或浏览器存储。提交 API 也不属于普通作者配置。

## 3. 车型配置

在内容树中添加或选择 `Test Drive Model`：

| 字段 | 必填 | 用途 |
| --- | --- | --- |
| `Model Key` | 是 | 稳定机器值，例如 `l9`；用于深链和门店关联 |
| `Model Name` | 是 | 页面展示名称 |
| `Subtitle` | 否 | 车型定位文案 |
| `Price Text` | 否 | 完整价格文案；为空时不显示 |
| `PC Image` | 是 | `1441px` 及以上使用 |
| `PC Image Alt` | 是 | PC 图片替代文本 |
| `Pad Image` | 否 | `1440px` 及以下使用；为空时回退 PC 图 |
| `Pad Image Alt` | 否 | Pad 图片替代文本；为空时回退 PC Alt |

PC 与 Pad 是两个独立 DAM 字段。当前现网 `drive-shop-config` 的 `bgPc` 和 `bgPad` 对每个车型使用同一张素材，因此当前 AEM 内容也配置为相同图片；后续提供专用 Pad 图时只改 `Pad Image`，无需改代码。

当前车型资产：

| 车型 | DAM 路径 |
| --- | --- |
| All-New Li L9 | `/content/dam/li-auto/shared/vehicles/li-l9/test-drive/li-l9-test-drive-pc-pad.png` |
| All-New Li L8 | `/content/dam/li-auto/shared/vehicles/li-l8/test-drive/li-l8-test-drive-pc-pad.png` |
| Li L6 | `/content/dam/li-auto/shared/vehicles/li-l6/test-drive/li-l6-test-drive-pc-pad.jpg` |
| Li L7 | `/content/dam/li-auto/shared/vehicles/li-l7/test-drive/li-l7-test-drive-pc-pad.jpg` |

不要下载页面上已经缩放为 `750px` 的 fallback 作为源文件，也不要直接粘贴公共 CDN URL。替换素材时上传现网原始文件到对应 DAM 目录，再通过字段选择。

## 4. 门店配置

在内容树中添加或选择 `Test Drive Store`：

| 字段 | 必填 | 用途 |
| --- | --- | --- |
| `Store Key` | 是 | 稳定机器值 |
| `City` | 是 | 城市或区域 |
| `Store Name` | 是 | 选择器展示名称 |
| `Available Model Keys` | 否 | 英文逗号分隔，例如 `l9,l8,l6,l7`；为空表示支持全部车型 |

车型和门店数量均由 item 驱动，不应在 JavaScript 中写死。修改 `Model Key` 时要同步检查所有门店的 `Available Model Keys`。

## 5. 响应式行为

- `1441px+`：左侧表单、右侧 PC 车型视觉。
- `720–1440px`：保持分栏，车型视觉使用 Pad 图。
- `719px-`：车型视觉在上、表单卡片在下，仍使用 Pad 图。
- Pad 图为空时自动使用 PC 图。
- 图片运行时保留 AEM 提供的最大 picture source，避免把 `750px` fallback 放大造成模糊。

## 6. 发布顺序

1. 发布新增或替换的四个车型 DAM 资产。
2. 将页面发布到 Preview，并确认页面引用的资产包含在发布范围。
3. 在 EDS Preview 完成远程验收。
4. Preview 通过后，再将页面及引用资产发布到 Live。
5. 确认 Edge Delivery Live 状态和 `.aem.live` 页面都已更新。

## 7. 远程验收

至少验证 `1920`、`1024`、`390px`：

- 根节点类名为 `lixiang-test-drive-booking block`。
- PC 使用 PC 字段，Pad 和移动端使用 Pad 字段或其 PC fallback。
- 图片原始宽度不小于渲染宽度，没有模糊放大。
- 四个车型分别切换到不同媒体，四个门店均可选择。
- 空表单显示姓名、邮箱和隐私同意错误，并聚焦首个错误。
- 页面无横向溢出、`.block-error` 或控制台错误。
- Universal Editor 内容树显示 4 个 `Test Drive Model`、4 个 `Test Drive Store`，车型 Properties 中可编辑 `PC Image` 与 `Pad Image`。

本地 `aem up` 和本地截图只用于开发检查，不代替远程 Preview/Live 验收。

## 8. 常见问题

| 现象 | 处理 |
| --- | --- |
| PC 图片模糊 | 检查 DAM 原图尺寸，并确认运行时使用 `width=2000` 的 picture source，而不是 `width=750` fallback。 |
| Pad 修改后没有变化 | 确认视口不大于 `1440px`，重新发布资产和页面，并强制刷新缓存。 |
| 车型切换后门店消失 | 检查门店的 `Available Model Keys` 是否包含当前 `Model Key`。 |
| Universal Editor 仍显示旧字段 | 确认组件模型已构建并推送到 `main`，重新打开编辑器标签页，不复用旧缓存画布。 |
| Preview 正常但 Live 未更新 | 先确认 AEM Live 发布成功，再检查 Edge Delivery 的 Live 状态和页面更新时间。 |

视觉与素材证据见 [`../lixiang-test-drive-booking-alignment.md`](../lixiang-test-drive-booking-alignment.md)。
